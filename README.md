# Gestión de Tareas

Aplicación web para administrar tareas de forma sencilla. Permite crear, editar, eliminar y marcar tareas como completadas. La información se almacena en `localStorage`.

## Instalación

1. Clonar o descargar el proyecto.

2. Abrir una terminal en la carpeta del proyecto:

   ````bash
   cd c:\wamp64\www\PHP-Kodigo\frontend\GestionDeTareas



3. Instalar las dependencias:
   ````bash
      npm install

4.Iniciar el servidor de desarrollo:
   ````bash
        npm run dev

 ````



## Características implementadas:
1.Crear nuevas tareas.

2.Editar tareas existentes.

3.Eliminar tareas mediante confirmación.

4.Marcar tareas como completadas o pendientes.

5.Filtrar tareas por:

Todas.
Completadas.
No completadas.

6.Guardar la información en localStorage.

7.Cargar datos iniciales de ejemplo.

8.Diseño responsive para teléfonos, tablets y computadoras.
